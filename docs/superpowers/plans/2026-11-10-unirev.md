# unirev 四合一逆向套件 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 rea、craft-anything、open-reverselab、reverse-skill 四个上游整合为一个 Claude Code 插件（新仓库 `unirev`），核心是统一路由技能。

**Architecture:** 路由大脑（skills/unirev）做纯 Markdown+JSON 的决策层；两个 GPL/MIT 上游以 git submodule 挂在 `vendors/`；rea 与 craft-anything 作为外部依赖由安装脚本拉取与校验；MCP 注册由安装脚本写入全局配置（避免插件内绝对路径不可移植与重复注册）。

**Tech Stack:** Markdown/JSON（技能层）、PowerShell 7 + Bash（脚本）、git submodule、npm（rea-agents）、GitHub Releases（craft-anything-cli）、uv/Python（reverse_lab_tools）。

**Spec:** `docs/superpowers/specs/2026-11-10-unirev-design.md`

## Global Constraints

- 仓库路径：`C:\Users\YPY\tools\unirev`；整体许可 **GPL-3.0-only**。
- 不复制上游代码进 unirev 本体；上游只经 submodule（open-reverselab、reverse-skill）或外部依赖（rea-agents、craft-anything-cli）引入。
- 不修改 vendors/ 下 submodule 的任何内容；定制只发生在 unirev 层文件。
- 上游版本基线：rea-agents ≥ 6.8.0；craft-anything-cli ≥ 0.6.0；submodule 跟踪各自默认分支。
- **实施偏差（经规格允许的落地调整）**：`.claude-plugin/plugin.json` 不内嵌 mcpServers——本机 rea/craft-anything 已全局注册（`~/.claude.json`），插件再注册会造成重名/重复连接，且 CLI 绝对路径不可移植。改由 install 脚本保证三个 MCP 全局可用（rea、craft-anything 检测已有则跳过；reverse_lab_tools 新注册，启动命令以 open-reverselab 自带 `.mcp.json` 为准：`uv run --project tools/skills/mcp/ReverseLabToolsMCP python tools/skills/mcp/ReverseLabToolsMCP/reverse_lab_tools_mcp.py`，路径前缀改为 vendors 内绝对路径）。
- 所有 PowerShell 脚本兼容 pwsh 7；Bash 脚本兼容 POSIX sh。
- 平台：Windows 优先（用户本机），.sh 为降级路径。
- 提交信息用英文 conventional commits；每个 Task 结束时提交。

- [ ] **Step 2: 写 scripts/route-test.ps1（失败版先跑）**

```powershell
#Requires -Version 7
$ErrorActionPreference = 'Stop'
$root = Split-Path -Parent (Split-Path -Parent $PSScriptRoot)
$routing = Get-Content (Join-Path $root 'skills/unirev/references/routing.json') -Raw | ConvertFrom-Json
$cases = Get-Content (Join-Path $PSScriptRoot 'testdata/routes.json') -Raw | ConvertFrom-Json

$fail = 0
$routeIds = @{}; foreach ($r in $routing.routes) { $routeIds[$r.id] = $r }

# 1) 结构校验：每条 route 必须有 id/signals/primary/kb(或明确无 kb)
foreach ($r in $routing.routes) {
  if (-not $r.id -or -not $r.signals -or -not $r.primary) { Write-Host "FAIL: route missing id/signals/primary"; $fail++ }
}

# 2) gates 与证据规则必须存在且 source 文件真实存在
if (-not $routing.gates.consent) { Write-Host 'FAIL: gates.consent missing'; $fail++ }
if (-not (Test-Path (Join-Path $root $routing.gates.source))) { Write-Host "FAIL: gates.source not found: $($routing.gates.source)"; $fail++ }
if (-not $routing.evidence.crossPhase) { Write-Host 'FAIL: evidence.crossPhase missing'; $fail++ }

# 3) kb 路径必须真实存在于 vendors
foreach ($r in $routing.routes) { foreach ($k in $r.kb) {
  if (-not (Test-Path (Join-Path $root $k))) { Write-Host "FAIL: kb dir missing: $k (route $($r.id))"; $fail++ }
} }

# 4) 用例的 routeId 必须在路由表中注册；声明 kb 的用例路径必须存在
foreach ($c in $cases.cases) {
  if ($c.expect.routeId -eq 'R-GATE-REJECT') { continue }  # 授权门拒绝路径无路由项，仅查 gates
  if (-not $routeIds.ContainsKey($c.expect.routeId)) { Write-Host "FAIL: case routes to unknown id: $($c.expect.routeId) [$($c.input)]"; $fail++ }
  if ($c.expect.kb -and -not (Test-Path (Join-Path $root $c.expect.kb))) { Write-Host "FAIL: case kb missing: $($c.expect.kb) [$($c.input)]"; $fail++ }
}

$total = $cases.cases.Count
if ($fail -gt 0) { Write-Host "route-test: $fail FAILURES / $total cases"; exit 1 }
Write-Host "route-test: all $total cases OK, $($routing.routes.Count) routes registered"
```

#!/bin/sh
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
fail=0
node -e '
const fs=require("fs"),path=require("path");
const root=process.argv[1];
const routing=JSON.parse(fs.readFileSync(path.join(root,"skills/unirev/references/routing.json"),"utf8"));
const cases=JSON.parse(fs.readFileSync(path.join(root,"scripts/testdata/routes.json"),"utf8"));
let fail=0; const ids=new Set(routing.routes.map(r=>r.id));
for(const r of routing.routes){ if(!r.id||!r.signals||!r.primary){console.log("FAIL: route missing fields");fail++;} }
if(!routing.gates.consent){console.log("FAIL: gates.consent missing");fail++;}
if(!fs.existsSync(path.join(root,routing.gates.source))){console.log("FAIL: gates.source missing");fail++;}
if(!routing.evidence.crossPhase){console.log("FAIL: evidence.crossPhase missing");fail++;}
for(const r of routing.routes){ for(const k of (r.kb||[])){ if(!fs.existsSync(path.join(root,k))){console.log("FAIL: kb missing "+k+" ("+r.id+")");fail++;} } }
for(const c of cases.cases){ if(c.expect.routeId==="R-GATE-REJECT")continue;
  if(!ids.has(c.expect.routeId)){console.log("FAIL: unknown route "+c.expect.routeId);fail++;}
  if(c.expect.kb&&!fs.existsSync(path.join(root,c.expect.kb))){console.log("FAIL: case kb missing "+c.expect.kb);fail++;} }
console.log(fail?("route-test: "+fail+" FAILURES / "+cases.cases.length+" cases"):"route-test: all "+cases.cases.length+" cases OK, "+routing.routes.length+" routes registered");
process.exit(fail?1:0);
' "$ROOT" || fail=1
exit $fail
